# ClearCast 1.2.1.0 screenshots

Actual, unedited application-window captures in Chinese (`zh-CN`) and English (`en-US`):

- Waiting for AirPlay, light and dark
- Music playback, light and dark
- Settings with the flowing music background, light and dark
- Windowed and fullscreen video playback

The demonstration uses original artwork, the supplied native vector illustration, fictional track/device names, and an original generated video with synthetic silence. It contains no private device content or third-party album art. The full-screen capture retains the display's native aspect ratio; the other captures use 1920 × 1080 or 2560 × 1440 windows. File dimensions and exact hashes are recorded in [provenance.json](provenance.json).
